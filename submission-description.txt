I created Morrow Coffee, a responsive cafe landing page, to demonstrate how a webpage can adapt to desktop, tablet, and mobile screens using semantic HTML and plain CSS. The page introduces the cafe with a hero section, shares its approach in a story band, presents three menu favorites, and provides its location and opening hours. The coffee, pastry, and latte photographs are displayed through image links in the HTML.

The layout changes at two breakpoints. Above 820 pixels, the hero places its text beside the image and the three menu cards appear in one row. At 820 pixels and below, the menu changes to two columns; the last card spans both columns and places its image beside the text. At 560 pixels and below, the navigation moves to a second header row, the hero stacks vertically, and each menu item becomes a horizontal card with a 110-pixel image beside its description. The story band wraps, and flexible heading sizes help content fit smaller screens.

The page uses CSS Grid, media queries, minmax(), clamp(), aspect-ratio, and object-fit to manage layout and image scaling. Semantic header, nav, main, section, article, and footer elements create a clear structure. Descriptive alt text, keyboard focus outlines, and reduced-motion support improve accessibility. One challenge was keeping menu descriptions readable as the cards became narrower. Instead of only shrinking the text, I changed the card arrangement at each breakpoint. Another challenge was fitting navigation on a phone without JavaScript; moving it to its own row keeps every link visible. The project is organized into index.html, styles.css, and README.md. The responsive review checklist covers desktop at 1440 pixels, tablet at 768 pixels, and mobile at 390 pixels, checking for overflow, overlap, readable cards, and undistorted images.
